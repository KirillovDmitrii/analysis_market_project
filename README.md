# Анализ рынка для интернет-магазина «Победа качества»

## О проекте
Проект посвящён анализу данных интернет-магазина «Победа качества», который продаёт товары для дома, детей, косметику, мелкую бытовую технику и продукты. Отчёт магазина показал снижение активности покупателей, и задача проекта — разработать решения для персонализированных предложений, чтобы удерживать активность постоянных клиентов.

## Цель проекта
- Маркировать уровень финансовой активности клиентов («снизилась» или «прежний уровень»)
- Сегментировать покупателей по поведению, маркетинговым коммуникациям и прибыльности
- Разработать рекомендации для увеличения покупательской активности

## Данные
Использовались следующие таблицы:

| Файл | Описание |
|------|----------|
| `market_file.csv` | Данные о поведении клиентов на сайте, коммуникациях, продуктовом поведении |
| `market_money.csv` | Выручка, полученная от каждого клиента |
| `market_time.csv` | Время, проведённое клиентом на сайте |
| `money.csv` | Среднемесячная прибыль клиента за последние 3 месяца |
| `forecast_chan.csv` | Вероятность снижения активности клиента (результаты модели DS) |

---

## 🛠 Процесс работы
1. **Загрузка данных** — импорт CSV, проверка кодировки, разделителей и корректности данных  
2. **Предобработка данных** — обработка пропусков, дубликатов и аномалий  
3. **Исследовательский анализ данных (EDA)** — визуализация поведения клиентов, выявление закономерностей  
4. **Объединение таблиц** — формирование единой таблицы с признаками для моделирования  
5. **Корреляционный анализ** — выявление зависимостей между признаками  
6. **Сегментация покупателей** — выделение ключевых сегментов с использованием модели прогнозирования и данных о прибыльности  
7. **Рекомендации** — предложения по персонализированным акциям и повышению активности клиентов  
8. **Выводы** — суммарные результаты анализа и рекомендации для бизнеса
